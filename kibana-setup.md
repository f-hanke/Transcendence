# Kibana Setup Guide with Security

## Prerequisites
Before starting, make sure you've set up Elasticsearch security:
```bash
make setup-elastic-security
```

## 1. Access Kibana
- Open your browser and go to: http://localhost:5601
- **You will now be prompted to log in**
- Username: `elastic`  
- Password: Check your `.env` file for `ELASTIC_PASSWORD` value
- Wait for Kibana to fully load (it may take a few minutes on first startup)

## 2. Create Index Pattern
1. Go to **Stack Management** → **Index Patterns**
2. Click **Create index pattern**
3. Enter index pattern: `microservices-logs-*`
4. Click **Next step**
5. Select **@timestamp** as the time field
6. Click **Create index pattern**

## 3. View Logs
1. Go to **Discover** in the left sidebar
2. Select your `microservices-logs-*` index pattern
3. You should now see logs from your microservices

## 4. Useful Filters
- Filter by service: `service: "webserver"`
- Filter by log level: `level: "error"`
- Filter by time range using the time picker

## 5. Create Visualizations
1. Go to **Visualize Library**
2. Click **Create visualization**
3. Choose visualization type (e.g., Line chart, Bar chart)
4. Select your index pattern
5. Configure metrics and buckets

## 6. Sample Queries
```
# All error logs
level: "error"

# Logs from specific service
service: "users-auth"

# Logs containing specific text
message: "login"

# Logs from last hour with errors
level: "error" AND @timestamp: [now-1h TO now]
```

## 7. Security Features
With security enabled, you now have access to:
- **User Management**: Stack Management → Security → Users
- **Role Management**: Stack Management → Security → Roles  
- **API Keys**: Stack Management → Security → API Keys
- **Audit Logs**: Monitor authentication and authorization events

## 8. Accessing Elasticsearch API
To access Elasticsearch API directly with security:
```bash
# Get cluster health (replace password with your actual password)
curl --cacert config/certs/ca/ca.crt -u elastic:YOUR_PASSWORD https://localhost:9200/_cluster/health

# Using environment variable (recommended)
export ELASTIC_PASSWORD="your_password_from_env_file"
curl --cacert config/certs/ca/ca.crt -u elastic:$ELASTIC_PASSWORD https://localhost:9200/_cluster/health
```

## Troubleshooting
- **Login fails**: Check your `.env` file for correct `ELASTIC_PASSWORD`
- **No logs appear**: Check that your services are running and generating logs
- **SSL/TLS errors**: Verify certificates are properly generated by checking `make logs`
- **Connection refused**: Ensure Elasticsearch is healthy: `make status`
- **Reset security**: If you need to start over, run `make clean && make setup-elastic-security && make up`

## Important Security Notes
- Default superuser is `elastic` with password from `.env` file
- Change passwords before production deployment
- Consider creating service-specific users with limited privileges
- Monitor the audit logs for security events
- Regularly rotate passwords and API keys
